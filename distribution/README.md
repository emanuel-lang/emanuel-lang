# Distribuciones listas para ejecutar

- **SIGEIA-XAMPP.zip:** para Apache + PHP 8.1 o superior. Descomprimir y copiar la carpeta `sigeia` a `htdocs`. Ver `LEEME-XAMPP.md`. No necesita Node.js ni MySQL.
- **SIGEIA-Platform.zip:** distribución Node.js original. Requiere Node.js 22 o superior; no es la carpeta para copiar a XAMPP.

Los paquetes no contienen cuentas, contraseñas ni registros personales. La demostración genera datos ficticios al primer arranque. Descargar el archivo deseado desde GitHub con «Download raw file». No es necesario descargar el código fuente completo para visualizar la aplicación.
